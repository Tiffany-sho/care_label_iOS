データ: `tools/.build/labels`

`tools/synth_label.py` のタグには、実物と同じように文字（素材表示・ブランド・注意書き）が入る。

取れなかった。文字が入っているかどうかで結果がまったく変わるので、こちらを主の指標とする。

## 表にない記号を読み飛ばす（2026-08-21）

実物のタグには JIS L 0001 の43記号に無い記号が載る。test_11 の
**中身のない丸**（クリーニング店向けの表示）がそれで、一番近い `610`
（丸に F）と断定していた。

丸の中身のインク率で見分ける。一番外側の輪郭の中心に、その半径の45%の窓を
置いて数える。実測:

| | インク率 |
|---|---|
| 中身のない丸 | 0.000 |
| `610` / `611` | 0.282 |
| `620` / `621` | 0.349 |
| `600` | 0.445 |
| `710`〜`712` | 0.536 |
| `700` | 0.719 |

0.15 で切る。0.20 まで上げると劣化画像で `611` を4枚落とす。0.10 まで下げても
落ちる枚数は変わらない（2322枚中2枚。どちらも別の基本形を丸と読み違えたもので、
もともと誤答だったもの）。

**クリーニングの表示は1枚も落とさないこと**を、きれいな画像129枚と劣化画像
2322枚で `tools/verify_outoftable.cjs` が確認する。
