## 公式リーフレットに形を合わせる（2026-08-21）

実写での相関が上がらない原因を、記号ごとに**インクの外接矩形の縦横比**で
突き合わせて特定した。公式とこちらで比が大きく違うものがそのまま
一致度の低い記号だった。

| 記号 | 公式の縦横比 | 直す前 | 一致度（前→後） |
|---|---|---|---|
| タンブルNG 300 | 1.289 | 1.000 | 0.35 → **0.87** |
| ウェットNG 700 | 1.225 | 1.000 | 0.38 → **0.69** |
| ドライNG 600 | 1.184 | 1.000 | 0.41 → **0.74** |
| 漂白NG 200 | 1.220 | 1.104 | 0.68 → 0.79 |
| 30℃洗濯機弱 141 | 1.094 | 1.056 | 0.38 → 0.55 |
| 40℃手洗い 110 | 1.360 | 1.173 | 0.43 → 0.54 |
| 40℃洗濯機弱 151 | 1.269 | 1.056 | 0.52 → 0.61 |

直したのは3か所。

1. **禁止の×は基本形より横に長い。** 四角や円の中に収めて描いていたが、
   公式は左右にはみ出す。これが 300 / 600 / 700 の一致度を落としていた最大の原因。
2. **洗濯桶は浅くて広い。** 大きな二山の波で深い桶を描いていたが、
   公式は小さい波が4つ並ぶ浅い桶。
3. **手は細長い。** 太い線を狭い間隔で並べていたので黒い塊に潰れていた。
   細くして間隔を空け、手首が桶の縁の上まで伸びる形にした。

公式との一致度の平均は 0.649 → **0.733**。
線の太さは公式もこちらも記号の大きさの 0.085 倍でほぼ同じだった（比 1.01）ので、
太さは原因ではない。

## 足切りの値を実写で引き直す（2026-08-21）

マージンの足切り 0.01 は**合成データで決めた値**で、実写にはきつすぎた。
実写91記号で振ると:

| マージン / 相関 | 正解 | 確定分の正解率 |
|---|---|---|
| 0.03 / 0.35 | 42 | 87.5% |
| 0.01 / 0.25（従来） | 54 | 80.6% |
| **0.005 / 0.20** | **60** | 77.9% |

実写は相関そのものが 0.3〜0.6 しか出ないのでマージンも小さくなる。

「確信度が低いものとして見せる」ほうを採る。
